# Privacy policy: Hidden Mechanics Uploader

Hidden Mechanics Uploader is a private tool used only by the owner of the Hidden Mechanics YouTube channel
(channel.hiddenmechanics@gmail.com) to upload and schedule the channel's own videos.

- It requests access to upload videos to, and read basic information about, the owner's own YouTube channel.
- It does not collect, store, sell or share data about any other person.
- Login credentials are stored encrypted as GitHub Actions secrets in this repository and are used only to upload the channel's videos.
- Access can be revoked at any time at https://myaccount.google.com/permissions.

Contact: channel.hiddenmechanics@gmail.com
